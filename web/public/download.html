CellStat

Statistical analysis for LibreOffice Calc and Excel. MIT License.

LibreOffice Calc

Download cellstat.oxt

  1. Install NumPy and SciPy for LibreOffice's Python, for example on Ubuntu: sudo apt install python3-numpy python3-scipy python3-sklearn
  2. In LibreOffice: Tools > Extension Manager > Add, choose cellstat.oxt, then restart LibreOffice.
  3. Select a table whose first row holds column names and choose CellStat > Open analysis panel.

Excel (web, Windows, Mac)

Download manifest.xml

  1. In Excel: Home > Add-ins > More Add-ins > My Add-ins > Upload My Add-in, and choose manifest.xml.
  2. Open Data > Analyze. The first run downloads the statistics engine (about 20 MB).
